# 🍔 BiteHub

BiteHub is a responsive restaurant website built with HTML, CSS, and JavaScript.

## 🚀 Features

- Browse food products
- Add products to the cart
- Increase and decrease quantity
- Remove products from the cart
- Calculate the total price automatically
- Prevent duplicate products in the cart
- Checkout functionality
- Responsive design for mobile, tablet, and desktop

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 📌 About The Project

This project was built as a Front-End practice project to improve my skills in HTML, CSS, and JavaScript, especially DOM manipulation, events, arrays, and responsive design.
